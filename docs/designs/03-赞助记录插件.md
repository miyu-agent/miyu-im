# 设计 03：赞助记录插件（草案）

状态：需求是 2026-10-23 项目主人在和旧 Miyu 比对后定的；技术形状照推荐写，施工前项目主人看过。

- 是 **im 插件**：通讯平台上的人给项目主人打钱，主人在群里、私聊里叫 AI「帮我记录一下赞助」。非常轻量。旧版是 `sponsor` 工具加赞助榜面板（`sponsor_tool.rs`、`sponsor_fx.rs`、`web/dash-sponsor.js`）。
- 编号 `miyu-im-sponsor`。单独的软件包：清单写 `[content.im]`，出现在 im 的插件页，从插件卡片的「打开面板」进它自己的后台页（设计 01 第四节第 5 条）。平台无关：QQ 现在用，接下来的 Telegram 照用。
- 代码住 im 仓库（一个 crate 加一个包目录），和 im 共用 CI、门禁，单独打包、单独装。

## 一、定了的

1. **记什么**：一笔一条。编号、谁（平台身份 `qq:123`、`tg:456`，加记账时的名字）、金额、币种、换成默认币种的金额和用的汇率（冻结，以后不变）、时间、备注；另记谁让记的（平台身份）、在哪个场所记的。
2. **给 AI 的工具一件**：`sponsor`。
   - 记一笔：谁（号；没写的照叫她的那一条引用的人、唯一 @ 的人认，同禁言）、金额、币种（不写的照默认）、备注。
   - 查：某个人的累计和明细（按号查，一个人两个号就是两行）、排行榜（可选平台、时间段）。
   - 改、删只在后台页，不给 AI（同「AI 不许删聊天记录」：这是钱的账）。
3. **谁能记**：只有管理员触发的那一轮能记（终端管理员、这个场所的管理的人）；别的答一句「只有管理员叫的回复才能记账」，进上下文、不发进群里（群里除了管理员的 `/` 命令回执不出系统消息，O-47）。查谁都能查。程序判断，不靠工具说明（和群管理工具「不挡人」不同：这是钱的账）。
4. **币种**：设置一项「默认币种」，出厂人民币，可改。别的币种照记账那一刻的汇率换成默认币种，汇率冻结进这一条。汇率自带查询（`open.er-api.com`，免费、不用 key，旧版同一家），查不到的照原币种记下、标「未换算」，后台补填，不猜（「算不准的钱不显示」）。现在不做共享的汇率库，以后第二个包要再拆。
5. **身份不合并**：按平台身份记，不把 QQ 号和 Telegram id 合成一个人；搜号、搜名字都行，能按平台筛；排行榜能选全部平台或某一个。
6. **后台页**（要美观实用，照 im 页面的设计语言：不画描边、同背景、悬停深一档、选中再深一档）：
   - 头上：总额（本月、今年、全部）和待补汇率的笔数。
   - 排行榜：按人累计（平台身份一人一行，带名字和平台角标），可选时间段、平台。全部列出，不截前几名（2026-10-27 项目主人：「榜单默认就只给前十这个设计不对，应该给完整的」，施工 I-60；她在群里查的、后台页的都是）。
   - 明细：新的在前，搜号或名字、按平台和时间段筛；点一条在浮窗里改、删（删要点两次）。
   - 「记一笔」浮窗：平台、号、名字、金额、币种、备注。

### 2026-10-24 补定

1. **认赞助人**：引用、@ 都认（项目主人：「只要填的时候能把 id 填进去」）：插件经 im 的 `chat.venue` 拿到叫她的那一条引用了谁、@ 了谁，带号和名字（施工 S-1 上a）。也收**只有昵称没有号**的赞助人（「有的人没 id」）：这一笔只记名字，按名字累计，排行榜、明细里单成一行。
2. **场所开关**：插件在某个群关着时，工具**不在**那个群的工具表里（项目主人：「不开就不应该出现在工具集，因为会无意义地消耗 token」）。核心 O-60：`provide` 的工具带 `plugin`（插件包写自己的编号），场所会话里只有 im 经 `venue.plugins` 告诉核心开着的才给，重启后没说过的场所一件都不给。im 驱动自带的群管理工具同样改（`plugin: "qq-admin"`）。原来写的「调到了回没开」作废。施工 S-1 上c 接上（核心钉 `7720cb73`）。
3. **认管理员**：照 `tool.call` 的 `owner`（核心认出的主人，群里主人的 `by` 带 `account`）或 `by.role` 是 `manager`；不往 im 要别的。

## 二、技术形状（照推荐）

1. **包**：清单 `capabilities` 要 `tools`（登记 `sponsor`）、`network`（查汇率）；`[page]` 后台页；`[content.im] dir = "im"`，`im/plugin.toml` 不写 `platforms`（哪个平台都行）。设置 `sponsor.currency`（出厂 `CNY`）。
2. **工具在哪个会话里有**：场所会话（群、私聊）开着这个插件的（im 插件的场所开关）。工具说明一句话，参数不写说明能省的都省（`docs/工具说明怎么写.md`），登记 `docs/ledger.md`、量 token。
3. **认管理员**：核心的 `tool.call` 带这一轮是谁触发的（`by`：外部身份、`role`）；`role` 是 `manager` 的（im 照场所的管理的人交），或者照对应表是终端管理员的，算管理员。不往 im 要别的。
4. **存**：包的状态目录里一份 JSON（一笔一条，改了整份原子写回），量小，不上数据库。
5. **后台页的方法**：经 `package.call`：`list {query?, platform?, from?, to?}`、`ranking {platform?, from?, to?}`、`totals`、`add`、`update`、`delete`、`rate {currency}`（补汇率时查一次）。

## 三、不做什么

- AI 改、删账。
- 合并同一个人的不同平台账号。
- 共享汇率库。
- 群里提示「记下了，等确认」这类系统消息（她自己回话里怎么说是她的事）。

## 四、要人验的

1. 群里你叫她「记一下 xxx 赞助了 50」：记上了，后台页看得到这一笔、排行榜跟着变。
2. 普通群友叫她记：没记上，她照常回话；群友问「谁赞助最多」她答得出。
3. 记一笔美元：换成人民币、带汇率；断网时记一笔：标「未换算」，后台补上汇率。
4. 后台页搜号、搜名字、按平台筛、改一笔、删一笔（点两次）。
