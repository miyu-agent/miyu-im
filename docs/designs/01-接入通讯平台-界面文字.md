# 接入通讯平台：界面文字

界面上的字（页名、按钮、提示、统计的标题）在这里；配置项（名字、小字、它管什么）在 `01-接入通讯平台-配置项.md`。项目主人直接改，样板、施工都照它们。

- 「名字」是这一项的标题；「小字」是名字下面那一行灰字，可以空着；「选项、默认」是值的写法。
- 写 `{平台的叫法}` 的地方由驱动给字：QQ 是「QQ 号」「群号」，别的平台照它自己的叫法。
- 只改字，不改格子的意思；要改意思的在「备注」里写一句。
