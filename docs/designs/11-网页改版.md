## 设计 11：im 网页改版

状态：已定（2026-11-05 项目主人定方向，11-06 看过方案页开工）。

### 一、要什么

11-05 项目主人说 im 网页「功能没问题，交互和前端很素、很简陋」，拿群管理面板举例：最近的管理记录和本周排行之间没有任何分界。定下来的方向：

1. **照网页软件的设置页**：一组设置一张卡片，组名写在卡片第一行，组和组之间留空。
2. **登录**：本机打开不要密码；从网页软件、终端跳过来带票据直接进；只有局域网访问要密码。
3. **局域网**：设置页加「访问」分组（向局域网开放、端口、局域网地址带复制和二维码）。局域网来的用核心的访问密码登录（11-06 项目主人当面定、核心的会话转达：不另设 im 自己的密码，原来 11-05 说的「im 自己的密码」不做）。
4. **使用限制**：先选平台、连接，再填号码，不再手写 `qq:10002`。最近 30 天按人的用量能搜、能筛。
5. **数据统计**：加按人、按会话的用量排行（能搜、能排序）和按天的走势图。
6. **凡是统计类的列表都能筛、能排、能搜**：会话概况的最近判断、群管理的管理记录和本周排行、使用限制的 30 天用量、统计页的排行。

人格、预设、模型三页是照网页软件做的，这次不动。

### 二、通用的改法

| 编号 | 改法 |
|---|---|
| G1 | 一组设置一张卡片（`.sect`）：组名在卡片第一行，组与组之间留空。插件声明的表单由 im 统一画，改一处全跟着变 |
| G2 | 「最近…」「排行」「按人」的列表头上一条：搜索框、筛选下拉、排序、时间段。超过 20 行分页加载。插件的列表不改核心的界面块（核心查得严，`list` 多一个键整块不收）：长列表的搜索、分页 im 画的时候加，按什么筛照插件自己的表单 |
| G3 | 「跟随默认值」从开关下面的一行字换成名字后面的小标签：没写的「默认」（悬停说跟着谁、是什么值），写了的「已改」（点了恢复默认） |
| G4 | 要填人的地方（使用限制、本人 ID、跳过判断的用户、管理员命令用户）先选连接，再填号码或从见过的人里搜着选 |
| G5 | 本机、带票据的不要密码；局域网要核心的访问密码 |
| G6 | 插件表单的「保存」放进它那张卡片的右下角，没改时不显示 |

### 三、各页

1. **会话浮窗**：
   - 触发方式分「什么时候说话」「主动回复判断」「权限」三张卡；发送消息处理分「说话方式」「怎么发」「长文」；限流与并发分「限流」「使用限制」「并发」。
   - 「多久看一眼」空着时框里淡字写现在用着的值（出厂 7 分钟，后端照调参交）。
   - 概况的最近判断进卡片，能筛「回了 / 没回」、能搜；六个数字一行排齐；「移出名单」放进最底下的「危险操作」卡片。
   - 群管理（插件表单）四段四张卡，「保存」进卡片；管理记录按动作筛、按人搜，排行切本周 / 本月。
2. **使用限制、本人的平台 ID**：选人控件（G4）；30 天用量加搜索、排序、「只看到了上限的」。「所有人」三格空着时淡字写「不限」。
3. **数据统计**：按人、按会话排行和按天走势（token、花费、回复次数可切）。回复率按「轮」算，拆开发的算一次。按小时的柱子加刻度、悬停显示数。
4. **设置**：「访问」分组（第一节第 3 条）。本机免密要核心让 im 扩展替本机页面换交接票（核心 LP-1：`login.ticket {via: "page"}`，要包批 `login.page` 能力）；im 只在对方是回环地址、`Host` 是本机写法、`Origin` 同源或没带时去换，远处来的一律要密码。
   - 挡不住的一种（核心的会话审 I-167补 时写明）：同机手配的反向代理把局域网请求转到 `127.0.0.1:<端口>`、把 `Host` 改写成本机（nginx 的 `proxy_pass` 默认如此）、又不加任何转发头，局域网里不是浏览器的客户端自己带上 `X-Miyu-Page`、不带 `Origin`，会被认成本机、不要密码。浏览器发的请求带 `Origin`，挡得住。所以别把 im 放在反向代理后面，要从局域网用就开 im 自己的局域网开关；设置页局域网开关的说明里写这一句。
5. **首页、消息记录、已安装、软件后台**：
   - 消息记录的筛选条一行；会话列表上面的机器人做成分组小标题。
   - 运行日志的安全记录（猜口令被拦）写成中文、用提醒色；「长文没转成图：unknown_package」写成「没装渲染包」并给「去下载」。
   - 「进站」改「收消息时」；面板名和软件名一样时只写一个。
   - 数字块一行排齐。
