## 下一版发版说明（草稿）

v0.3.6（im、im-sponsor 两份清单 0.3.6，施工 I-274，含到 LW-IM-9）以后的改动。发版时照这里写 Release 的说明，发完清空。新的一条插在这一节最前面。

- Windows 版不再需要 VC++ 运行库：没装过「Microsoft Visual C++ 2015–2022 可再发行组件」的电脑上，以前会报「找不到 VCRUNTIME140.dll」、打不开，现在可以直接运行。
- AI 的一轮出错没回成时（例如上下文超过模型窗口、自动压缩已暂停），接入通讯平台的运行日志（`miyu im logs`）会记下是哪个群或私聊、什么原因，不用再翻会话日志找。
