## 下一版发版说明（草稿）

v0.3.4（im、im-sponsor 两份清单 0.3.4，施工 I-270，含到 I-269）以后的改动。发版时照这里写 Release 的说明，发完清空。新的一条插在这一节最前面。

- 管理页面和 Miyu 网页界面的同类页面统一了样子和说法：下拉都换成同一种，搜索框带放大镜，选中的一项、正在输入的框不再变成白色；侧栏的「已安装」改叫「软件包」，顺序和网页界面一致；不经网页界面、直接打开管理页面时，也用网页界面的配色。
- 数据统计照网页界面的用量页：token 分成缓存命中、没命中的输入、输出三样，颜色一致；时间范围多了「全部」和「自定义」，默认 30 天，头上显示几点更新、能刷新；按模型、按用途的表多一列命中。
- 模型、人格、预设、设置几页的说法照网页界面（例如「主对话的模型」「旗舰池」「按先后」「思考程度」「局域网访问」），人格、预设的编辑里显示 id，人格的记忆一行写有几条；设置里打开局域网访问时提示它不加密。
- 首页在名单还空着时写「名单里还没有群和私聊」，不再写成「还没有会话」；窄屏上的大浮窗铺满整屏。
- 管理页面「模型」里，Antigravity 这类不需要密钥、地址的供应商，不再显示密钥那一块；编辑时只显示它用得上的几项，原样保存也不会把软件包给的接口写进你的配置。
- 管理页面模型列表和数据统计里，能看图的模型标成「多模态」，和 Miyu 设置页的说法一致。
