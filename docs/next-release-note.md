## 下一版发版说明（草稿）

发版时照这里写 Release 的说明，发完清空。新的一条插在这一节最前面。

- 她能往群里、私聊里传文件（`qq_send_file`）：把她工作区里的文件交给 NapCat 上传，im 不设大小上限，QQ 收不了的照 QQ 的原话告诉她。要求 NapCat 和 Miyu 在同一台机器上。**Windows 上暂时不能传**：传之前要核对文件没被换掉，Windows 上现在还核不了，以后能核了再开。（I-130）
- 新命令 `miyu im records import <文件>`：把别处的聊天记录（设计 04 第四节的 JSON Lines）导进 im 的记录库，重导、和已有的重叠都不会多出来。（I-127、I-128）
- 发图等 NapCat 回应放宽到 30 秒，图其实发到了不会再告诉她「没人看见」。（I-129）
- 端口被占时提示的换端口命令去掉了 `--system`。（I-125）
