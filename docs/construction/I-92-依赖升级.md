## 施工单 I-92：依赖升级

状态：做完了（2026-10-30；发布前的许可证和漏洞审查交来的第 3 条）。

### 目的

审查报告点名 im 的依赖锁里几个版本有已知问题：`rustls` 要 ≥ 0.23.46、`rustls-webpki` ≥ 0.103.16、`webpki-roots` ≥ 1.0.10、`ctutils` ≥ 0.4.4；`yoke-derive` 0.8.3 被撤下（yanked）了。

### 怎么走

只改 `Cargo.lock`：`cargo update -p rustls -p rustls-webpki -p webpki-roots -p ctutils -p yoke -p yoke-derive`。

| 包 | 原来 | 现在 |
|---|---|---|
| rustls | 0.23.45 | 0.23.46 |
| rustls-webpki | 0.103.15 | 0.103.16 |
| webpki-roots | 1.0.9 | 1.0.11 |
| ctutils | 0.4.2 | 0.4.7 |
| yoke、yoke-derive | 0.8.3 | 0.8.4 |

### 不做什么

- 别的依赖不跟着升（`cargo update` 只点这几个）。
- 发行包的许可证（Lucide 原文、AGPL、第三方清单）是 I-93。

### 验收

本机门禁（含许可证门禁）、三台 CI 全绿。
