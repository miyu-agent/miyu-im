## 施工单 I-50：后台页几处小改

状态：做完了。

### 目的

项目主人 10-27 在后台页上走了一遍，提了几处：

1. 设置页的「账号绑定」改成「平台 ID 和用户账号绑定」，新绑定的输入框提示里不要有具体的 QQ 号、账号名，只写「ID」「账号名」。
2. 统计页「为什么回、为什么没回」那一段去掉。
3. 会话卡片「随机触发主动回复判断的概率」从拖动条改成填数值。
4. 会话卡片上「继承（…）」看不懂：改成「跟随默认（…）」。
5. 选模型的小窗搜索不是模糊匹配。

### 改了什么

- 设置页：绑定那一段的标题、说明三种语言换掉；两个输入框的提示照新加的 `settings-page/bind-id`、`settings-page/bind-account`。
- 统计页：「为什么回、为什么没回」不画了，三种语言那一组字（`stats/reasons`、`stats/reason-*`）删掉。宿主照旧交，页面不用。
- 会话卡片的千分比那一格（`controls.js` 的 `percent`）：
  - 改成一个填百分数的输入框，后面跟「%」，存的照旧是千分比。
  - 空的是跟随默认，提示里写着现在用着的数；读不出数的照字交给宿主报错。
- 「继承（…）」「继承默认人格」三种语言改成「跟随默认（…）」「跟随默认人格」（英文 Default、日文既定）。
- 选模型（`shell/picker.js`）：
  - 新加 `fuzzy`：照空白拆词，每个词都要找得到，先后不论；整个出现的算 2 分，字照先后零散出现的算 1 分。比如「g38f」配得上「gemini-3.8-flash」。
  - 组名也算进去，搜「dev」能挑出那一组。
  - 一组里照分数排，一样的照原来的先后。

### 验收

本机门禁 `cargo xtask check` 全过，CI 三台全绿。模糊匹配在 node 里跑过：「gemini flash」「3.8 flash」「flash gemini」「g38f」都配得上「dev antigravity/gemini-3.8-flash-tiered」，「claude」配不上。界面随部署由项目主人看。
