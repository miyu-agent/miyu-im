## 施工单 O-58（上）：场所卡片的后端

状态：已合（7cbdb6f，2026-10-18，run 39043953559）。O-58（下）是后台页的「群」「私聊」两页（版式 A：左边列表、右边详情，样子照 2026-10-17 给项目主人的样式页）。

### 目的

项目主人 2026-10-17 定：

1. 后台页按场所给卡片：白名单里的群一张、白名单成员一人一张；「其他群」一张兜底（出厂关着）。版式 A。
2. 群相关四项挪进卡片：群白名单、白名单以外的群、两档限流从配置项里去掉；睡觉时间、触发词、看得到 QQ 号留在配置项里当默认，卡片里能单独改。
3. 私聊卡片就是白名单成员：加卡等于加白名单成员，删卡等于移出；`onebot.whitelist` 照旧算数，卡片只存额外的设置。
4. 前端凑活，重在后端。

### 卡片

- **存在哪**：`state/packages/onebot/cards.json`，和状态文件同一个目录。由桥读写：先写临时文件，再改名。
  - 不放核心的配置：核心配置没有「每个群一组设置」这种结构。
  - 不写进 `system/venues.d/`：那是管理员手写的，页面写进去会冲掉注释。
- **几格**：每张卡都是可选的格，没写的照下面几层。
  - 群卡：
    - `on`：接不接话，拼成 `allow`。
    - 规则已有的格：`persona`、`extra_prompt`、`keywords`、`managers`、`sleep`、`rate`、`show_ids`。
    - `chatty`：插嘴，四档 `never | few | some | many`。`never` 拼成 `discipline = "when-called"`，另外三档拼成 `chatty = { probability = 千分比 }`。
    - `strip_period`：拼成 `outbound = { strip_period = … }`。
  - 「其他群」卡：同群卡，没有号。
  - 私聊卡：`persona`、`extra_prompt`、`strip_period`。睡觉、限流本来就不管白名单成员，所以不给。
- **怎么拼成规则**：
  - 拼成 `70-cards.toml`，来处和配置项那一份一样是 `Settings`，排在 `60-settings.toml` 后面。
  - 先后：「其他群」那条在最前面（匹配全部群），每个群一条，每个私聊一条。
  - 问题、来处说成卡片：哪一张卡、哪一格。
  - 系统里手写的规则，名字排在后面的照旧盖过卡片。
- **两个方法**（页面调）：
  - `cards.get`：交回
    - 卡片；
    - 每一格的默认值和来处（照卡片下面几层套出来的）；
    - 她在的群（`get_group_list`：号、名字、人数）；
    - 好友（`get_friend_list`：号、昵称）；
    - 人格的名字（核心的 `persona.list`）。
    - 群、好友问不到的照空的交，页面写号。
  - `cards.save {cards}`：
    - 先拼成规则、交群聊内核读；有问题的不存，原样交回问题（哪一张卡、哪一格、原因码）。
    - 没问题的写盘、当场换上，下一条消息就照新的套。

### 要拍板的

无，上面两题项目主人 2026-10-17 已定。施工时定的：
