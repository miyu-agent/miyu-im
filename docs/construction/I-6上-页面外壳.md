## 施工单 I-6 上：页面的外壳、首页的连接卡、`miyu im web`

状态：合了（`080a1e2`，run 39213990408）。

### 目的

设计 01 第八节第 1、2、8 条和第九节第 3、4 条的头一段（2026-10-19 项目主人定 I-6 接着 I-5 做）：im 自己的页面有了外壳（侧边栏、几页的入口、主题、和宿主说话的那一层），首页画连着的机器人；`miyu im web` 带交接票打开它。新建连接的引导、连接设置随 I-6 中；今天的数字、运行日志随 I-6 下；会话、插件、统计、设置几页随 I-7 以后。样子照样板 `d-im.html`。

### 怎么走

1. **页面的文件分文件夹**（第八节第 8 条）：`site/` 下外壳在 `shell/`（侧边栏和路由 `shell.js`、主题 `theme.js`、通道 `channel.js`、登录 `login.js`、字 `i18n.js`），一页一个文件夹在 `pages/`，字在 `texts.js`。页面服务的路径一段一段用 `/` 隔开，最多 4 段，每段照原来的规矩查。
2. **外壳**：侧边栏头上名字和在线状态（「在线 · N 个机器人」「没有连接」「连不上接入通讯平台」），首页、会话、插件、商城、统计、设置（还没做的灰着写「即将」），底下切深浅、登出。收起、展开、收起以后指针靠到最左边浮出来，照网页软件的左栏；收没收起记在浏览器里。窄屏左栏盖在内容上，进来时收着。哪一页照网址的 `#`。
3. **主题**：从 WebUI 跳过来的照片段的 `scheme`、`colors`（网页软件 `design.js` 页面那一组的名字，下划线换连字符写成 CSS 变量，只认页面用到的那几个，值里不许有 `;{}`），记在这个标签页里，不给手动切；单独打开的跟随系统，能在跟随系统、浅色、深色之间切。
4. **通道**：宿主多一个方法 `connections`：连着的每个机器人的平台、号、连上的时刻、问到了的实现和版本（`Bots` 记下连上的时刻）。桥手里的状态变了（NapCat 连上、断开、认出号、问到实现，配置推来，页面服务换端口）推一帧 `{"event": "changed"}`，页面照它再问，不轮询（原来叫状态文件的 `Notify` 换成一个计数，`crate::changed`，状态文件和页面都照它）。通道断了过一会儿再连（1 秒起翻倍，最多 10 秒），4401 回登录页。
5. **首页**：没有连接的写「还没有连接任何平台」；有的一个机器人一张卡（头像先是平台的字母、平台的角标、号、平台和实现、在线和连了多久，每分钟照本机的钟重画）。
6. **`miyu im web`**：照终端的样子连已经在跑的核心，`extension.status` 说 im 在跑、状态文件的进程号对得上、写着页面服务的端口，才要一张交接票，拼 `http://127.0.0.1:<端口>/#miyu=<base64url({"v":1,"ticket","lang"})>` 交给系统打开，标准输出上印网址（打不开浏览器的说一分钟内有效）；im 没在跑的说先 `miyu im start`。原来转给网页软件 `miyu web --package im` 的那一套去掉。

### 施工时定的

- 页面服务不给 `style=` 属性（内容安全策略只许同源），平台角标的颜色用 class（`pf-qq`）；脚本改 CSS 变量走 CSSOM，不受影响。
- 机器人的名字、头像要驱动另问平台（OneBot 的 `get_login_info`、头像地址），页面又不能直接连外网（内容安全策略），随 I-6 中一起做（宿主取来经页面服务给）。这一步卡上名字的位置先写号。
- 断开的机器人这一步不留卡（`Bots` 断开就拿掉）；「断开的写在重连」要宿主记下见过的号，随 I-6 中。
