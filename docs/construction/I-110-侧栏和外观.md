## 施工单 I-110：侧栏和外观

状态：做完了（2026-11-02；项目主人用部署时提的第 7、9、10、20 条）。

### 目的

1. 首页运行日志左边的色条一行接一行连成一条线，读不清。
2. 装了网页软件时，主网页能跳到 im 网页，im 网页跳不回去。
3. 左下角「登出」没必要（只给一个人用）；「源码」换成 GitHub 的标志。
4. 设置里要有「外观」页；左下角的深浅切换不要「跟随系统」那一档。

### 图纸改哪几节

- 设计 01 第八节第 1 条：侧栏底下一行的样子。

### 怎么走

1. 活动日志的色条从整行的左边框改成缩进上下各一截的一条，行和行之间断开。
2. 宿主新 `site/web_link.rs`：`web.status`（核心的包列表里有没有 `miyu-webui`）、`web.open`（替这个人向核心要一张交接票 `login.ticket`，60 秒作废，拼成 `http://127.0.0.1:<web.port>/#ticket=<票>`；没装的回 `not_installed`，读不到端口的回 `no_port`）。网页那头早就认 `#ticket=`（网页的 `served.js`）。
3. 侧栏底下：去掉「登出」；源码换成 GitHub 标志（图标表里画一个，lucide 没有品牌标志）；装了网页软件的多一个「主网页」，点了先开一个空的新标签页（等票再开会被当成弹窗挡掉），要到地址再换过去，打不开的提示一句。
4. 深浅：左下角照现在显示的换成另一个（跟随系统时照系统现在的深浅算），图标画现在的样子；设置页多「外观」一段，跟随系统、浅色、深色三档；两处改了互相跟着变。从网页软件打开的照网页软件的颜色，「外观」那三档灰着、写一句为什么。

### 验收

- 截图自测（假数据测具）：首页运行日志（色条断开）、侧栏底下（深浅、主网页、GitHub）、设置「外观」浅色和深色。
- 部署上验：点「主网页」打开主网页且是登录的。
