## 施工单 I-179：后台页由 im 自己的网页服务提供

状态：做完了（2026-11-09；发版前检查第 14 条「不装网页也能看软件后台」，项目主人定了做法，core1 转来）。

### 为什么

im 的后台早就是它自己起的网页服务（`site/`，`status` 回应带 `web` 端口），清单却还写着 `[page] dir = "page"`，包里留着 O-28 时期那份静态后台页。网页、托盘照清单以为 im 有静态页，开出来的是旧页面或者只有顶栏的整页。核心 BP-1（04ba8a92b）让清单能写 `[page] server = true`：后台页由程序自己的服务给，`package.list` 带 `page_server: true`，`package.file` 回 `no_page`。

### 怎么改

1. 核心的钉从 5ff659669 换到 04ba8a92b（含 BP-1；钉住的旧核心不认 `server`）。
2. 清单 `[page]` 改成 `server = true`，删掉 `miyu-im/page/`。
3. 发版的结构检查从 `page/index.html` 改查 `site/index.html`。
4. 测试：`backstage` 改成断言列表带 `page_server`、`package.file` 回 `no_page`，去掉逐个比对静态页文件；`page` 只查 `site/`；`pronoun` 去掉删了的 `page/texts.js`。

核心的新命令 `miyu pkg page miyu-im`（BP-2）开页面时片段只带 `{v, ticket, lang}`：im 的页面换票只看 `ticket`，主题不带 `scheme`、`colors` 时照 im 自己记的那一档或跟随系统，不用改。

### 坑

- `site/texts.js` 原来不在「给人看的字不写她」那条检查里，这次核对时发现「说话方式」提示里写了「她」「She」（`field/style-note-hint`、`field/style-note-defaults`）。没有并进这一步，另排。

### 验收

- `backstage::the_page_reaches_the_bridge_through_the_core`：清单退回 `dir = "page"` 时报红（列表没有 `page_server`）。
- 本机门禁、三台 CI 全绿。
