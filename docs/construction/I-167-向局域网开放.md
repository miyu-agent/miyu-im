## 施工单 I-167：设置页「访问」，向局域网开放

状态：做完了（2026-11-06；设计 11 第三步）。本机免密拆到 I-167补，等核心 LP-1。

### 为什么

im 网页原来只听 `127.0.0.1`，局域网里的手机打不开，也没地方开。项目主人 11-05 定照网页软件的「访问」做；11-06 当面定（核心的会话转达）局域网来的用核心的访问密码登录，不另设 im 自己的密码。

### 怎么走

1. **配置**：清单加 `im.web.listen`（文本，出厂 `127.0.0.1`）。im 只认两种写法：`0.0.0.0` 是向局域网开放，别的都照本机（`site/listen.rs`）。
2. **监听**：
   - 页面服务照 `listen` 的地址开 `port`。
   - 同一个端口只换地址时（开关局域网），旧的占着这个端口，新的开不上（`Address already in use`）。改成先放下旧的再开，开不了的照原来的地址开回来（`site.rs` 的 `rebind`）。已经接进来的连接不断。
3. **认地址**（`site/guard.rs` 的 `allowed_host`）：开着局域网时，`Host` 写 IP 的也收。写域名的照旧只认本机的三种写法，DNS 重绑定照样挡得住。`Origin` 照旧要同源。
4. **局域网网址**：听 `0.0.0.0` 时，照网页软件的做法问系统往外走用哪个地址（UDP 套接字连文档地址 192.0.2.1，不发包）。`settings.get` 多交 `listen`、`lan`（`地址:端口`），`settings.set` 收 `listen`，只收两种写法。
5. **页面**（设置页「网页服务」改叫「访问」，换成共用卡片 `shell/sect.js`，`sect` 加一句小字）：
   - 「向局域网开放」开关、端口。
   - 开着的再给一张卡（`pages/settings/lan-card.js`，照网页软件的 lan-card）：左边二维码，右边等宽网址和「复制」，下面一句扫码怎么登录。问不到地址的写一句。
   - 二维码白底黑块，深色主题也不反过来。
6. **二维码**：照网页软件原样搬 `shell/qr/`，其中 qrcode-generator 2.0.4 是 MIT、原样没改。许可证进 `xtask notices` 的第三方数据，`THIRD-PARTY-LICENSES.txt` 重新生成。

### 不做什么

- im 自己的访问密码：项目主人 11-06 定不做，共用核心的。
- 本机免密：I-167补。要核心 LP-1，扩展连接上 `login.ticket {via: "page"}`，要包批 `login.page` 能力。

### 验收

- 本机门禁、三台 CI 全绿。
- `site/tests.rs` 的 `a_lan_listener_also_takes_ip_hosts_but_never_names`、`site/listen/tests.rs` 两项。
- `tests/site.rs` 的 `opening_to_the_lan_keeps_the_port_and_takes_ip_hosts`：同一个端口开、关局域网，写 IP 的 Host 开着收、关了 421，域名一直 421。不加第 2 条的先放下旧的时，它是红的。
