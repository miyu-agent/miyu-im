## 施工单 I-46：赞助记录插件在真核心上装得上了

状态：做完了。

### 目的

10-27 部署新 im 接项目主人的真 QQ 时，赞助记录插件装不上，核心回「settings.currency.type 只能是 bool、int、option、text、name、url、secret 或 list（第 32 行）」。清单里默认币种那一项写了 `type = "string"`，核心从来只认 `text`。

插件自己的测试都是假核心，没走核心装包时查清单的那一道，所以一直没暴露。

### 改了什么

- `sponsor/package.toml`：默认币种 `type = "text"`。插件读到的照旧是字符串，代码不用改。
- 新加 `crates/miyu-im-sponsor/tests/manifest.rs`：用核心的 `miyu_config::package::read` 读真清单，读不进就红。插件的开发依赖多 `miyu-config`，跟工作区钉的核心同一版。

### 测试

- 清单改回 `string` 时这条红，报的就是部署时撞到的那一句；改成 `text` 以后绿。
- 本机门禁 `cargo xtask check` 全过，CI 三台全绿。

### 验收

部署的数据根上 `miyu-remake pkg install --yes --system <赞助插件的包文件夹>` 装得上；插件页里有「赞助记录」。
