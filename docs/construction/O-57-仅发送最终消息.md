## 施工单 O-57：仅发送最终消息

状态：已合（a00a2b8，2026-10-18，run 39137699378）。

### 目的

项目主人定（2026-10-18 重申，之前定过）：场所卡片一格「仅发送最终消息」，开了的场所只发她这一轮最后那段话，她调工具时说的话不发。群聊出厂开，私聊出厂关；群卡、「其他群」卡、私聊卡都能改。原来叫「分步发送」「每一步都发」，O-51 施工单那句「群里只发这一轮最后那段字」是过时的说法：桥本来每一步都发（`tests/followed.rs` 里跟着工具调用说的「第一段。」照样发进群）。

### 蓝图改哪几节

- `chat.md` 第八条：出站参数多 `outbound.final_only`（开关，出厂参数 `false`）。
- `onebot.md`：新加「仅发送最终消息」一节；「场所卡片」三种卡多 `final_only` 一格（并进 `outbound` 表）；「场所卡片的两页」的「发出去」一组多这一格；出厂场所规则群那一条打开它。
- `onebot/data/venues.d/50-defaults.toml`：群那条规则多 `outbound = { final_only = true }`。

### 怎么走

1. **判**：这个场所此刻的参数 `final_only`（群出厂规则开、私聊照出厂参数关，卡片、系统规则能改）。
2. **扣着**：设了的场所里，她的一条回复（`message.assistant`）带工具调用块的，里面的字先扣着（照「她说话的那条线、回合编号」记，同一回合再扣的换掉它，空的不扣），不发。
3. **最后那段**：同一回合后面一条不带工具调用的回复就是最后那段：当场发，扣着的丢掉；它没有字的发扣着的（兜底：核心现在不收空的回复，会接着请求）。
4. **回合结束**（`turn.ended`）还扣着的（她最后一步带着工具调用、工具结束了这一轮，例如发表情包）：这时发出去。
5. **这一轮不说话了**（`skip_reply`）：扣着的丢掉，同原来不说话的那一轮。
6. **补发**（桥重启以后期限以内没入队的）：设了的场所里带工具调用的那几步不补。
7. 群里主线、支线、私聊同一个办法（`speak.rs` 的 `say_or_hold`、`turn_closed`；扣着的记在 `quiet.rs`，和「不说话」放在一起：都是「这一轮哪些不发」）。

### 施工时定的

- 照「这条回复带不带工具调用」认中间那几步，不等回合结束才发：最后那段平常是不带工具调用的，照旧当场发、不多等。
- 测试的卡片给「其他群」关了这一格：原来的测试测的是别的事，照老的每一步都发；新行为另外写测试。
- 「她」不进给人看的字（代词门禁）：顺手把 O-58 下的「群里怎么叫她」改成「触发和插嘴」，门禁多查卡片两页的字和出厂场所规则。

### 不做什么

- 功能开关、「其他私聊」卡（各自一步）。
