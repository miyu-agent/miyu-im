## 施工单 I-257：界面中文照文档规矩改写，凭证叫法统一

状态：做完了（2026-11-19），等项目主人验收。

### 起因

2026-11-19 项目主人定了核心 AGENTS.md「文档的规矩」，经 core1 交来两件，并进 0.3.1 之前做：

1. 中文界面上「key」「密钥」混用的统一写「密钥」，参数名、配置键不变。
2. im 后台页和插件给人看的字照「文档的规矩」过一遍：保持简短，去掉省略到看不懂的短句、「她」和内部说法。「终端管理员」不改。

同日问过 core1 后一起做的两件（core1：都在主人定的范围里）：

3. NapCat 连接用的凭证，中文界面里「Token」「令牌」「密钥」三种叫法混用，统一写「令牌」。模型的凭证才叫「密钥」，用量里的 token 不变。
4. `miyu im` 命令行的输出和帮助一起改。

### 改了什么

只改中文，英文和日文不变；键名、配置键、参数名不变。

凭证叫法：
- 模型那边：「粘贴 API Key」「改用 API Key」改成「粘贴密钥」「改用密钥」。
- NapCat 那边：「验证 Token」「粘贴 Token」改成「验证令牌」「粘贴令牌」。原来把 NapCat 凭证叫作「密钥」的那条提示，也改成「令牌」。
