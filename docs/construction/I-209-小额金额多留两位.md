## 施工单 I-209：查用量的工具里不到 1 的金额多留两位

状态：做完了（2026-11-11）。

### 现象

`qq_token_usage`、`tg_token_usage` 答的金额固定两位小数。一个人一天常常只花几厘钱，写出来是 `0.00 USD`，读着像没花钱（core1 审 I-206 时提的）。

### 改了什么

`toolset/common/usage.rs` 的 `digits`：照网页用量页的写法，不到 1 的留到四位、后面多出来的 0 不写（`0.0832`、`0.004`、`0.50`）；不是 0 可四位都是 0 的写 `<0.0001`；1 以上照旧两位。只改数的写法，工具说明、回执的模板都没动，登记簿不用改。

### 怎么验

- 单元测试 `numbers_and_money_read_like_a_person_wrote_them` 多了六个数。
- 没测到的：真有价钱的模型上她读到小额以后怎么说。
