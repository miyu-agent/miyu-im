### 改了什么

- `im/package.toml`、`im-sponsor/package.toml` 的 `version` 0.3.5 → 0.3.6。赞助记录照惯例和 im 一起升。
- 核心下限照旧 `2026.11.0-rc.2.4`。核过的依据：
  - im 自己 0.3.5 以后的改动没有新调用核心的方法，`program.rs`、`serve.rs`、`settle.rs` 改的是堆和线程。
  - 钉从 `62d294acd` 换到 `030b896d7`：im 和核心说话用的 `miyu-ipc`、`miyu-client` 两个 crate 一行没变。
  - 内核事件改成装盒子（LW-10 上）只改了在内存里的样子，读写的 JSON 不变。唯一多出来的字段 `builtin` 带 `serde(default)`，没有就当假，rc.2.4 的核心不写它也读得通。
  - 主人本机的核心是 rc.2.8（`6f234638a`），是这一钉的上一步，中间只有 LW-26 共用给人看的字，不碰协议。
- 发版说明草稿清空，开头改成「v0.3.6 以后的改动」。Release 的说明照「文档的规矩」写给用户：
  - 内存、线程少了。
