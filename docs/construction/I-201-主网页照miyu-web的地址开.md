## 施工单 I-201：侧栏「主网页」照 `miyu web` 的地址开

状态：做完了（2026-11-10），没有在真环境里点过。项目主人阶段验收后「发版前的 check」第 17 条。

### 为什么

项目主人：im 网页侧栏跳主网页走的是 8300 端口，不对，应该走 `miyu web` 命令。

查代码：`web.open` 不是写死 8300，是问核心的系统配置 `web.port`（出厂 8300）再拼 `http://127.0.0.1:<端口>`。主人那一次为什么不对没能复现（验收目录的配置里 `web.port` 是 48300，照说拼出来是对的）。但这个做法本身靠不住：配置的端口是「下次起来想听的」，不是网页软件这时真在听的（`miyu web --port` 起的、换了端口还没重起的都对不上），网页没在跑时更是开到一个没人听的地址。

### 怎么改

`site/web_link.rs`：`web.open` 先跑一次主程序的 `web --print`（主程序照 `program::main_program` 找，最多等 15 秒），拿它印的地址（网页软件自己记在 `run/web` 里的那一个；没在跑的 `miyu web` 会先拉起来），去掉 `#` 后面的一次性码，接上 `#ticket=<交接票>`。跑不成、没印出地址的退回原来的办法照 `web.port` 拼。

### 验收

- 单元测试：印出来的地址去掉 `#` 后面和末尾的 `/`；印的不是地址的当没有。
- 没测到的：真的跑 `miyu web --print`（测试环境里没有网页软件）。
- 主人实测：在验收目录的 im 网页侧栏点「主网页」，开的是这个环境的网页界面（48300），并且直接是登录的。还不对的话请告诉我点的时候 im 网页的地址和跳到的地址。
