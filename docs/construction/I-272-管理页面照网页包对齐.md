## 施工单 I-272：管理页面照网页包的同类页面对齐

状态：做完了（2026-11-22），排进下一版，不单独发版。

### 起因

core1 转达主人（11-22）：im 管理页面每一页整页截图，和网页包同类的页面并排看，找出所有不一致的地方。对照报告一共 75 条，其中 31 条在统计、软件、设置、im 独有的几页和外框，44 条在模型、人格、预设。报告放在本机 `~/.cache/miyu-remake/pages-audit/report*.md`，没进仓库。

core1 回话：以网页包为准，im 跟着改，一次做完报告的一、二、三节。疑似网页包自己的问题转给网页会话。第五节主人和 core1 定了：

1. 分段切换的选中、输入框的聚焦都不许变白：选中深一档，聚焦是底色加聚焦影。
2. 网页包弹窗外面那 1px 边框不算描边，网页包保留。
3. 统一叫「软件包」，im 的卡片形态保持。
4. 模型池调用方式的第三档用核心字表的「按先后」。
5. 人格、预设的编辑里都显示 id，预设列表带副标题，「新建」用主色。
6. 单独打开的 im 先不加语言项。配色先跟网页包统一；主题不能只存在 sessionStorage 里，新开标签页也要记得。

### 改了什么

**底子**（`base.css`、`shell/`）：
- 分段切换选中的一格改成 `surface-3`，不再变白。输入框、多行框聚焦时底色不变，只加软影。首页日志切换的选中也照此改。
- 新加两个共用部件：
  - 自绘下拉 `shell/menu.js`：用法同原生 `<select>`，有 `.value` 和 `change`。弹出的卡片里，选中的一项打 ✓；暗着的项点不了；键盘的上下键、回车、Esc 都能用。
  - 带放大镜的搜索框 `shell/search.js`。
- 原生 `<select>` 全部换成自绘下拉，共 13 处。所有搜索框都加了放大镜。下载软件的搜索框原来聚焦时出一圈 3px 主色外圈，现在和别处的输入框一样。
- 侧栏的「已安装」改叫「软件包」，顺序照网页包：模型、预设、人格；下载软件、软件包、软件后台。网址里的编号不变。
- 网页包交来的颜色，照浅色、深色各记一份进 localStorage。单独打开（新标签页、书签）时，照现在的明暗换上记着的那一份；手动切换明暗、系统明暗变了，都换成对应的那一份。
- 补上网页包的中文标点字体（`Miyu CJK Punct`，只用本机黑体）。`<small>` 定为 12.5px。
- 加了提醒用的橙字 `--warn`。原来的提醒用 `--gold`，而网页包交来的 gold 是灰紫，看不出是提醒。
- 窄屏：
  - 大浮窗铺满整屏，只问一句的小浮窗照旧浮着。
  - 从宽屏缩到窄屏时，侧栏自动收起。
  - 会话浮窗的分页放不下时换行，不再横着滚。
- 删除这类按钮改成灰底红字。点不了的主按钮改成灰底灰字。

**数据统计**（照网页包的用量页）：
- token 分成缓存命中、没命中的输入、输出三样，写缓存算进没命中的输入。颜色也照网页包：命中浅，没命中深。
- 几格数的名字、先后照网页包：花费、请求（几个会话）、token（输入和输出各多少）、缓存命中（命中多少）、每次回复的 token。
- 明细表：
  - 按模型、按用途两张表上下排，各多一列命中。
  - 模型名不再带供应商前缀，供应商用灰字接在后面。
- 时间范围多了「全部」和「自定义」（两个日子），默认 30 天。头上写几点更新，加一个刷新按钮。
- 宿主的 `stats`（`site/stats.rs`）：
  - 认 `period: all`：从计数里最早的那一天起算，用量不设起点，也不和前一段比。
  - 认 `period: custom`：带 `from`、`until`，含头含尾。尾在今天以后的算到今天；日期写错、头在尾后面、超过 3660 天的回 `bad_params`。
  - 按模型、按用途的每一项多带 `hit_rate`。
  - 「按人」的个人账本跟着按起止查（`spent::ranking` 多了尾）。
- 「Token」一律写成小写的 token。

**模型**：
- 三个分页挪到标题下面、靠左，用标签条：没有槽，选中深一档。
- 默认模型：
  - 行名、说明取核心字表，例如「主对话的模型」「新会话默认使用的模型。」。
  - 不再包卡片，行之间一条线。
  - 选模型的按钮上画供应商图标和模型名，供应商名用灰字接在后面。
  - 内置模型没装的提示改成橙字，紧贴在说明下面。
  - 窄屏上下拉单独占一行。
- 模型池：三个固定池叫「旗舰池」「日常池」「轻量池」，调用方式写「按先后」。
- 模型的设置：
  - 「思考程度」。
  - 「支持输入」只列选了的，每个带 ×，最后一个 + 弹出没选的几项。
  - 窗口框 96 宽、等宽字。价格分两列。各项之间一条线。
- 供应商一列：行高 34，选中照侧栏带影子；详情头的图标 28，名字 16px。
- 重名模型的编号另起一行，窄屏上也能完整读到。
- 添加供应商：行高 44；「已找到密钥」用主色淡底；分组名用粗体。

**人格、预设**：
- 编辑里都有 id 一行。

- 「子代理可用」；副标题「决定 AI 的人格和记忆」；无人值守步数的占位字是「空着照出厂的 500」。
