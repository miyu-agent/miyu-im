## 施工单 I-47：新建连接的浮窗有动画，密钥默认遮住、眼睛看原文

状态：做完了。

### 目的

项目主人 10-27 走一遍配置流程时提的两条：

1. 点「新建连接」浮窗是一下子冒出来的，上一步、下一步换屏也没有过渡。
2. 反向连接的验证 Token 没有默认遮住，要做一个眼睛图标看原文。

### 改了什么

- `shell/dialog.js`：
  - 打开时先让浏览器算一遍起点的样子再加 `open`。原来等下一帧再加，常常和起点算在同一次里，过渡被跳过。
  - 新加 `swap(children, back)` 换中间的内容：新内容从右边滑进来，往回翻的从左边；浮窗的高度跟着变过去，不跳。
  - 系统要求少动画的（`prefers-reduced-motion`）不做。
- `pages/home/wizard.js`：各屏照编号换，往前翻的从右、往回的从左，同一屏重画的不动。
- 新加 `shell/secret.js`：密钥框默认圆点遮着，右边一个眼睛按钮，点一下露出原文、再点遮回去。新建连接、连接设置、插件设置里的密钥都用它。
- 眼睛的两个图标进 `index.html` 的图标表。提示字「显示」「隐藏」三种语言。
- 按钮不描边，照底色。

### 测试

浏览器实测（无头 Chromium 接调试口，每 25 毫秒采一次样）：

- 打开：层的透明度 0 → 1，浮窗从 0.97 放大到 1，约 150 毫秒。
- 下一步：中间的内容从右 16 像素滑到 0，透明度 0 → 1，浮窗高度 274 → 231 一路变过去。
- 上一步：从左 −16 像素滑进来。
- 密钥框：默认 `password`；点眼睛变 `text`，提示变「隐藏」。

截图看过：图标对、没有描边。纯页面的改动，没有 Rust 测试能守。

本机门禁 `cargo xtask check` 全过，CI 三台全绿。部署后在 im 网页首页点「新建连接」，看浮窗淡入、放大；点下一步、上一步，看滑动方向；到 Token 那一步，看默认是圆点，点眼睛看原文。
