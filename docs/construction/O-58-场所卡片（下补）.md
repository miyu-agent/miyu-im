## 施工单 O-58（下补）：表单的默认值带 value

状态：已合（0ffba13，2026-10-18，run 39080200126）。

### 目的

网页那头 2026-10-18 照真卡片走 O-58 下时提的：开关、下拉的默认值头只拿到「默认 · 开」这句字，`null` 画不出默认是开是关，人一点就交了和默认一样的值。核心 X-15 三补（b11a6f7b）让表单一格的 `default` 能带 `value`：`{"text": "默认 · 开", "value": true}`，照控件查类型，不收 `null`。

### 做了什么

- 每一格的默认值有值、类型对得上控件的，`default` 多写 `value`（`rules/cards/page/parts.rs` 的 `default_value`）：开关是布尔，数字是数，一行字、多行字是字，列表是字的数组（管理的人去掉 `qq:`，同 `value`），下拉要是选项里的值。没有的、类型对不上的、下拉里没有的（默认的人格删了）不写。
- 核心钉到 349378a9（含 X-15 三补 b11a6f7b；b11a6f7b 本身 Windows 的 CI 红，核心 3-9 七补修好）。
- 蓝图 `onebot.md`「场所卡片的两页」第 3 条加上 `default.value`，第 8 条去掉这一项。

### 验收

- 门禁全过；`src/rules/cards/page/tests.rs` 多一条：插嘴的默认带选项里的值、管理的人只写号、人格、开关是布尔、阈值是数，没有默认的不写，默认人格不在选项里的、类型对不上的不写。端到端的两页照新核心的写法检查也过（写错了核心整块拒）。
