## 施工单 I-116：连接地址只收 IP

状态：做完了（2026-11-02；发布前审查第四轮 I4-2，低）。

### 目的

后台页新建、改连接时地址收任何不空的字；驱动读连接表时读不出 IP 的照默认 `0.0.0.0`。人写 `localhost` 想只给本机，结果所有网卡都开着（失败时偏开放）。

### 怎么走

1. 驱动读连接表（`Settings::all`）：地址写了却读不出 IP 的那一个连接不开，记一行 `connection host not an address, not opened`；没写的照默认（同原来）。原来只有一个连接的老写法（I-27）不动。
2. 宿主 `connection.add`、`connection.edit` 的地址只收 IP 的写法，别的回 `bad_params`。
3. 页面：连接设置里地址改了、宿主说写错了的写「地址要写成 IP，例如 127.0.0.1、0.0.0.0」。

### 验收

- 审查给的原样测试 `tests/audit4.rs::a_host_that_is_not_an_address_does_not_open_every_interface`（连同 `Settings` 的 use）加回来：**在没改的代码上跑是红的**（红在断言那一行），改了以后绿。复核照它（`cargo test -p miyu-im-onebot --test all audit4`）。
- `tests/site_connections.rs`：加、改连接时地址写 `localhost` 都拒 `bad_params`。
- 本机门禁、三台 CI 全绿。
