## 施工单 I-188：群的场所说明按平台写

状态：做完了（2026-11-10；I-185 上实测时看到的，项目主人当天定「按平台写」）。

### 为什么

- 群会话的 system 尾部有一段场所说明，照模板 `data/system/group.txt` 写，原来是 `<venue>QQ group "{name}" ({id})</venue>`。
- Telegram 的群也照它写成 `QQ group "Miyu 测试群" (-1001)`，AI 会以为自己在 QQ 群里。

### 怎么改

1. 平台多一个给模型看的叫法：`Platform::labeled`，驱动给，OneBot 是 `QQ`、Telegram 是 `Telegram`。
   - 认平台照旧只认名字：相等、哈希都只比名字。
   - 宿主不写死平台。
2. 模板换成 `<venue>{platform} group "{name}" ({id})</venue>`，字段多一个 `platform`，群会话照这个群的平台填。
3. QQ 群写出来的字节和以前一样，缓存不受影响。只有 Telegram 群的 system 尾部变一次。

### 验收

- 集成测试：
  - `titled`：QQ 群写出来的那一段还是 `<venue>QQ group "…" (…)</venue>`，逐字节对上。
  - `telegram_tools`：Telegram 群的 system 里是 `<venue>Telegram group "Miyu 测试群" (-1001)</venue>`；退回旧模板，这个测试报红。
- 登记簿：QQ 复量 17（没变），Telegram 20。
- 本机门禁、三台 CI 全绿。
