## 施工单 O-49：群名和群号带给她

状态：施工中。

### 目的

项目主人 2026-10-17 定：她在群里要知道是哪个群，群名、群号都带上。

### 蓝图改哪几节

- `onebot.md` 新加「群名」一节，`bridge.json` 的表加 `group_info_seconds`，清单的 `capabilities` 加 `context.system`。
- `docs/ledger.md` 登记 `onebot/data/system/group.txt`。

### 要拍板的

无（形式是技术题，照推荐定）。施工时定：
- 放在 system 尾部（核心的 `system.append`，单给这个群会话），不写成事实：一直在、压缩不掉；群名很少改，改了才换一次。
- 群名是群里的人改得了的字：照模板的规矩转义、截到 64 个字符、裹在 `<venue>` 标签里。
- 问 NapCat 的 `get_group_info`，问到了隔一小时（`group_info_seconds`）再问；问不到的这一次不放。
- 支线分叉以后照主线的放一份，支线第一次请求的 system 和主线一样。

### 不做什么

- 私聊不放对方的名字（没要）。
- NapCat 推来的改群名通知不另接：隔一小时再问就跟上了。

### 验收

- 群里终端管理员 @ 她两次：两次请求的 system 一样、最后是那一段、只有一段，运行日志一行 `group title set`；私聊没有。
- 支线的 system 和主线的照旧逐字节一样（`lanes.rs`）。
- 这一段量 token、登记：17 个（`摸鱼群`、9 位群号）。
- `group_info_seconds` 是 0：两条消息问两次，名字没变的只放一次。
- 变异 11 个全红：群消息不放、支线不放、隔够了的边界、不记问的时刻、一样的照交、不记放过的、群名不洗、字段换错、不带会话、动作名、问错群号。
- `cargo xtask check` 全过；三平台 CI 绿。
