## 施工单 I-68：设置页只填本人的号

状态：做完了。

### 目的

核心 SU-3 下把 `external.me` 并进 `external.bindings`：键是平台身份，值不空就算主人本人，写 `owner` 或老的 `admin` 都一样。只有一个主人，设置页「平台 ID 和用户账号绑定」那一段的账号名一格没有意义了。

### 改了什么

1. 宿主（`site/settings.rs`）：
   - `settings.get` 的 `bindings` 从「身份 → 账号」的表换成身份的列表，只交值不空的。
   - `settings.set {"key": "binding:<身份>"}` 的值：`true` 写 `owner`，`null` 去掉那一条，别的答 `bad_params`。
2. 页面（`settings.js`）：一个身份一行，只有号和「解除绑定」。新绑定只有一个输入框，存的值是 `true`。账号名那一格、`.binding-account` 的样式、`settings-page/bind-account` 三种语言都删掉。
3. 名字（项目主人 10-28 定）：段名「本人的平台 ID」，小字「这些 ID 发来的消息算你本人」。设计 01 的配置项、界面文字两份跟着改。
4. 测试：
   - `site_settings.rs` 照新形状断言：列表里有身份；加的那一条在系统配置文件里写的是 `owner`；值写字、写 `false` 的答 `bad_params`。
   - 测试的系统配置 `qq:10001` 改写 `owner`，小号 `qq:10007` 留老的 `admin`：两种写法都认。

### 验收

本机 `cargo xtask check` 全过。页面在 8771 那类环境里开设置页看一眼：只有号、没有账号名，加一个、去掉一个都能存。
